# YeelightBar Homebrew Tap

This is the official Homebrew tap for [YeelightBar](https://github.com/bekircem/YeelightBar), a native macOS menu bar controller for Yeelight bulbs on your local network.

## Install

```sh
brew install --cask bekircem/yeelightbar/yeelightbar
```

YeelightBar requires macOS Ventura 13 or later and supports Apple Silicon and Intel Macs.

## Update

```sh
brew update
brew upgrade --cask yeelightbar
```

## Uninstall

```sh
brew uninstall --cask yeelightbar
```

To also remove YeelightBar's sandbox container and preferences:

```sh
brew uninstall --cask --zap yeelightbar
```
